# 配置与首次使用

GoScanner 是 CLI 应用。可选配置文件固定放在：

```text
~/.config/goscanner/config.json
```

macOS 和 Linux 使用相同位置；不使用 macOS 的 `Application Support` 目录，也不读取 `XDG_CONFIG_HOME`。`~` 表示当前用户的主目录。程序不在仓库中查找实际配置。唯一的自动写入场景是：用户从发现列表明确选择设备后，将该设备登记为默认设备。

## 1. 必须满足的基本条件

这些是使用前提，不是可以填写为 `true` 的配置项。

- 扫描仪已开机，支持 WSD 扫描。当前仓库未集成 USB 扫描，不支持 eSCL-only 设备。
- 电脑能够访问扫描仪所在的可信局域网。自动发现仅支持直连 IPv4 局域网；VPN、客户端隔离、防火墙和本地网络权限可能影响连接。
- 若 macOS 提示本地网络访问，请按需允许实际运行程序的应用访问。连接失败不一定是扫描仪离线。
- npm 包仅支持 macOS 14+、Apple Silicon，并自带 OpenCV 动态库。源码构建则需要自行准备 OpenCV；即使关闭 AI，也不能省略该构建链接的 OpenCV。源码构建见 [源码构建与 AI 运行环境](build.md)，npm 分发方式见 [npm 安装与发布](npm.md)。
- 保存位置可写，有足够的磁盘空间，且文件系统支持硬链接。新建输出目录使用 `0700`，最终文件使用 `0600`；程序不更改已有目录的权限，不覆盖已有文件。
- npm 包已包含 AI 模型与 ONNX Runtime，不需要手动准备。源码构建需在启用 AI 前准备它们。程序不会自动下载模型或上传扫描图像。

不需要为 WSD 扫描安装 Python、HP 驱动、Avahi 或 SANE。程序不会自动授予权限、更改系统设置或启动试扫。

## 2. 创建配置文件

首次使用可直接运行 `./bin/goscanner-ai info`，在终端选择设备。程序只登记 `device`，其他设置继续使用内置默认值；`info` 不启动扫描。

也可从仓库根目录执行下列命令建立初始配置；如果文件已存在，先检查它，不要覆盖：

```bash
mkdir -p "$HOME/.config/goscanner"
# 仅在目标文件不存在时复制。
cp -n config.example.json "$HOME/.config/goscanner/config.json"
chmod 600 "$HOME/.config/goscanner/config.json"
```

示例与内置默认值一致：

```json
{
  "device": {
    "host": "",
    "port": 8018,
    "path": "/wsd/scan"
  },
  "scan": {
    "dpi": 150,
    "mode": "color",
    "area": "a4",
    "timeout": "30s"
  },
  "output": {
    "directory": ".",
    "format": "jpg"
  },
  "processing": {
    "deskew": false,
    "autocrop": false
  }
}
```

必须使用 JSON 语法，不支持注释或尾随逗号。可以省略不需要设置的字段。例如，只指定保存目录：

```json
{
  "output": {
    "directory": "~/Documents/GoScanner"
  }
}
```

## 3. 配置项

| 配置项 | 类型 | 内置默认值 | 用途与限制 |
| --- | --- | --- | --- |
| `device.host` | 字符串 | `""` | 扫描仪 IP，不含协议、端口或路径；留空时发现并要求确认选择。适用于 `info`、`scan` |
| `device.port` | 整数 | `8018` | 扫描服务端口，范围 1–65535；只在指定 host 时使用 |
| `device.path` | 字符串 | `"/wsd/scan"` | 以 `/` 开头的 URL 路径，不含空白、查询参数或片段；只在指定 host 时使用 |
| `scan.dpi` | 整数 | `150` | 必须大于零，且被设备横向、纵向分辨率列表同时支持 |
| `scan.mode` | 字符串 | `"color"` | `color` 或 `gray`，设备也必须支持对应模式 |
| `scan.area` | 字符串 | `"a4"` | `a4`、`full`，或 `x,y,width,height`，单位为毫米，原点是平板左上角；范围必须符合设备能力 |
| `scan.timeout` | 字符串 | `"30s"` | 大于零的 Go 时长，例如 `30s`、`2m`；仅适用于 `scan` |
| `output.directory` | 字符串 | `"."` | 非空的保存目录；不存在时尝试创建。相对路径基于执行命令时的当前工作目录 |
| `output.format` | 字符串 | `"jpg"` | `jpg`、`tiff`、`png` 或 `pdf`；不带点，使用小写 |
| `processing.deskew` | 布尔值 | `false` | AI 纠偏，只旋转，不裁切 |
| `processing.autocrop` | 布尔值 | `false` | AI 裁切，只裁切，不旋转 |

`scan`、`output`、`processing` 各组仅影响 `scan` 命令。

### 设备地址与首次选择

只填写 IP 即可使用默认端口和路径。例如：

```json
{
  "device": {
    "host": "192.168.1.8"
  }
}
```

上述配置连接 `http://192.168.1.8:8018/wsd/scan`。默认端口和路径适用于已验证的 HP 1188w，不代表所有型号通用。其他设备可以设置 `port`、`path`，或留空 `host` 通过发现取得实际地址。

`host` 必须是 IP，不接受 URL、DNS 主机名或凭据。IPv6 地址填写不带方括号的原始 IP。`path` 中已有的百分号转义会保留。仅支持 HTTP，不要把 WSD 端口暴露到互联网。

`info`、`scan` 在命令行和配置均未指定 host，且未使用兼容参数 `--endpoint` 时：

1. 自动发现设备，输出名称、型号和扫描地址。
2. **即使只有一台，也必须输入编号并按 Enter 确认。** 空输入不是确认；编号无效时重新提示。输入 `q` 或按 Ctrl+C 取消。
3. 把选中地址拆成 `host`、`port`、`path`，登记到 `~/.config/goscanner/config.json`。
4. 保存成功后继续当前命令。`info` 只读查询；`scan` 开始扫描。后续命令直接使用已登记设备，不再重复选择。

发现零台时停止。发现有警告但仍有可用设备时，先显示警告，再由用户明确选择；不自动采用第一台设备。设备选择读取交互终端，不从重定向的标准输入自动确认；非交互任务须用配置或命令行提供 host。

`discover` 仍只输出发现结果的 JSON 数组，不选择设备、不登记配置。JSON 结果中的 `endpoint` 是设备发布的完整地址，与配置文件字段不同。已指定设备但连接失败时，不自动切换设备。

登记默认设备时，重新读取最新配置，仅更新 `device`，保留其他设置；缺少文件时创建。通过同目录临时文件、同步和原子替换保存，文件权限为 `0600`。保存失败时终止当前命令，不创建扫描任务。已有配置损坏或为符号链接时拒绝自动覆盖；请先手动修复或设置 device。不要同时运行多个首次登记流程或在保存瞬间并发编辑配置。

重新选择设备时，将配置中的 `device.host` 改为空字符串。端口与路径会采用新选中设备的实际值。

**旧配置迁移：** 配置文件不再接受 `device.endpoint`。例如，将 `http://192.168.1.8:8018/wsd/scan` 拆为：

```json
{
  "device": {
    "host": "192.168.1.8",
    "port": 8018,
    "path": "/wsd/scan"
  }
}
```

删除旧的 `endpoint` 字段；不自动修改旧配置。命令行 `--endpoint URL` 仍保留兼容入口。

### 保存目录与格式

默认在**执行命令时的当前工作目录**直接生成 `scan-时间戳.jpg`，不再自动放入 `scans/` 子目录，也不是保存在配置文件或可执行文件所在目录。

`output.directory` 支持：

- `.`：当前工作目录。
- `scans`：当前工作目录下的 `scans/`。
- 绝对路径。
- `~` 或 `~/...`：当前用户主目录。不支持 `~其他用户`，不展开 `$HOME` 等环境变量。

未指定 `-o` 时，文件名自动带时间戳，扩展名来自 `output.format`。连续扫描沿用现有的页号规则；PDF 默认合并。没有配置固定文件名，避免后续扫描与旧文件冲突。

命令行 `-o` 指定完整输出文件路径，同时覆盖 `output.directory` 和 `output.format`，以文件扩展名决定格式。指定路径的父目录不存在时尝试创建。请让 shell 展开命令行中的 `~`，不要把它放在引号内。

PDF、连续扫描以及 AI 原图备份需要额外空间。云同步目录可能自动上传扫描件；敏感文档应保存在非同步目录。

### 超时

`scan.timeout` 默认 `30s`。自动发现和选定设备后的操作分别计时，设备选择等待不计入超时。手动模式按每页扫描计时，不包含换页等待。取消本客户端已创建任务时，清理最多额外等待 10 秒。本地图像处理、PDF 合并和文件系统调用不是硬实时可抢占操作。

`discover` 默认超时仍为 `10s`，`info` 默认仍为 `2m`。两者可通过本次命令的 `--timeout` 覆盖，不读取 `scan.timeout`。

### AI 处理

两项 AI 开关独立。同时启用时先纠偏再裁切；启用时额外保留设备原图。检测不可靠或处理失败时可能输出原图，并发出警告。模型误定位仍可能裁掉内容，需要核对原图。

高级路径继续使用已有环境变量，不在配置文件中重复设置：

```text
GOSCANNER_MODEL_PATH
GOSCANNER_ONNXRUNTIME_PATH
```

它们分别覆盖模型文件与 ONNX Runtime 动态库的完整路径。npm 命令默认使用包内文件，非空环境变量仍可覆盖。源码默认路径、版本、模型 SHA256 和处理限制见 [AI 预处理准备](build.md#ai-预处理准备)。版本和模型校验不是普通用户可关闭的配置项。

## 4. 优先级与临时覆盖

```text
显式命令行参数 > 配置文件 > 内置默认值
```

- 缺少配置文件或省略某项时，使用内置默认值。
- `--host`、`--port`、`--path` 分别覆盖对应设备字段。只传 `--host` 时，端口和路径仍按“配置 > 内置默认值”解析；host 为空时，port/path 不用于限定发现结果。
- 兼容参数 `--endpoint URL` 同时覆盖整组设备配置，不能与 `--host`、`--port`、`--path` 同时使用。
- `--dpi`、`--mode`、`--area`、`--timeout` 覆盖对应扫描默认值。
- `--deskew=false` 和 `--autocrop=false` 可以临时关闭配置中启用的处理。布尔参数需要使用等号，不要写成 `--deskew false`。
- `-o` 覆盖默认输出目录和格式。
- 显式命令行参数只用于本次命令，不会写回。只有从发现列表确认选择设备时，才登记该默认设备。

例如：

```bash
# 只读查询设备能力与状态，不启动扫描。
./bin/goscanner-ai info

# 使用配置和内置默认值；没有 host 时先确认选择，再开始扫描。
./bin/goscanner-ai scan

# 本次改用 300 DPI、2 分钟超时，并临时关闭 AI。
./bin/goscanner-ai scan --dpi 300 --timeout 2m --deskew=false --autocrop=false

# 本次保存为指定的 PDF，忽略默认输出目录和格式。
./bin/goscanner-ai scan -o ~/Documents/document.pdf
```

手动连续扫描、PDF 每页独立保存和固定文件名仍使用本次命令参数：`--manual`、`--single-page`、`-o`。`--single-page` 要求最终输出格式为 PDF，可以通过配置或 `-o` 选择。程序不提供启动后自动扫描或扫描自动重试配置。

## 5. 错误处理

- 文件存在但无法读取、JSON 格式错误、未知字段或字段类型不匹配时，明确报错，不静默退回默认值。错误会指出配置文件路径。
- 配置必须只有一个顶层 JSON 对象。
- 完成命令行覆盖后，仅校验当前命令实际使用的值。扫描参数无效、地址不合法或输出配置无效时停止；命令行已覆盖的配置值不再使用。
- `info` 和 `discover` 不校验扫描参数的取值、不创建输出目录，也不加载 AI 模型；但整个文件仍须能通过 JSON 格式、字段名称和类型解析。
- 设备不支持所设分辨率、色彩、范围或格式时，在创建扫描任务前报错，不自动降级或改扫其他设备。
- AI 启用但模型或运行库不满足要求时，在创建扫描任务前失败；关闭 AI 时不要求这些文件准备完成。
- 配置文件损坏时，仍可运行 `--help` 或子命令的 `--help` 查看帮助。

请勿在配置中保存密码、令牌或其他认证内容。实际配置仅在本地使用；仓库只保存示例与说明。
